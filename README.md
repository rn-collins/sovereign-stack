# The Sovereign Stack

A working proposal prepared for Purple Maiʻa: a community-authority governance and learning layer for AI systems.

The prototype demonstrates a possible decision protocol, living system record, bounded pilot path, and optional learning translation. It is explicitly a proposal—not Purple Maiʻa policy, community consent, or an approved protocol.

## Local development

```bash
npm install
npm run dev
```

The repository is configured for automatic Vercel builds through `vercel.json`.
